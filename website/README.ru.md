# OrcaSlicer Agent — статический сайт

[English](README.md) | [Русский](README.ru.md)

Двуязычная страница проекта (английский по умолчанию, русский по `/ru/`): описание форка, демонстрация модели и нарезки,
возможности, инструкция установки через ИИ, ручная установка и FAQ.

Канонические исходники находятся в `website/` основного форка OrcaSlicer.
`dist/` содержит готовые файлы: HTML, CSS, JavaScript, локальные шрифты и изображения.
Английская версия находится в `dist/index.html`, русская — в `dist/ru/index.html`;
обе используют общий `dist/app.js` и содержат переключатель языка.
Сборка, npm, база данных и серверная логика не требуются.

## Локальный просмотр

Из корня форка:

```sh
python3 -m http.server 8080 --directory website/dist --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080` для английской версии или `http://127.0.0.1:8080/ru/` для русской. Обе страницы содержат переключатель языка. Файлы можно также открыть напрямую;
для копирования предусмотрен fallback, а для ручного выделения текст доступен
даже без JavaScript. FAQ и ручная инструкция используют HTML `details`.

## Размещение

Публикуйте содержимое `website/dist/` на любом статическом хостинге.
Для GitHub Pages выберите **GitHub Actions** в Settings → Pages. Workflow **Agent website** автоматически публикует `website/dist/` после изменения сайта в `main`; ручной запуск также доступен. Остальная часть репозитория не загружается в Pages.

Зеркало: https://outsid3rx.github.io/OrcaSlicer/. Основной SEO-домен остаётся https://orca-agent.ru; настройки DNS не меняются.

Используются относительные пути: подходит и размещение в подкаталоге GitHub Pages.
`.openai/hosting.json` содержит только идентификатор публикации Sites
и путь к статическим файлам; этот файл не нужен для обычного статического хостинга.

Сайт не выполняет установку: он копирует читаемый промпт или команды.
Промпт установки универсален для stdio MCP-клиентов: например, Codex, Claude Desktop, Cursor, Windsurf и ZCode, с учётом возможностей конкретного клиента. Селектора клиента нет. Ручная установка по умолчанию выдаёт универсальную конфигурацию; `--client codex` и `--client zcode` доступны как необязательные варианты автоматической настройки. Код страницы не обращается
к слайсеру, MCP, принтеру, аналитике или сторонним API. Шрифты включены локально;
внешние сервисы открываются только по ссылкам пользователя.

Без `--client` установка настраивает только MCP-сервер и печатает его конфигурацию stdio; навык автоматически не устанавливается. Для других клиентов перенесите включённый в комплект каталог `skills/orca-mcp-control/` по инструкции установки навыков вашего клиента. Если клиент не поддерживает навыки, примените инструкции из `SKILL.md` как руководство проекта.

## Обновление содержания

Сверяйте инструкцию с `docs/agent/INSTALL.ru.md`, скриптом `scripts/agent/install.sh`
и навыком `skills/orca-mcp-control/SKILL.md`. Не объявляйте неподтверждённые релизы,
платформы или принтеры поддержанными. Проверка `doctor` не доказывает подключения
к окну Orca. Не добавляйте разрешение печати в установочный промпт.

## Дизайн и материалы

Светлая дизайн-система из предоставленного локального референса: серый холст, точечная сетка,
белые округлые поверхности, жёлтая/чёрная пара кнопок и акценты синего, красного,
персикового цветов. Nunito Sans используется как предложенная замена Poppins
с поддержкой кириллицы; Inter — для основного текста.

Шрифты распространяются по SIL Open Font License; тексты лицензий находятся
в `dist/assets/*-OFL.txt`. Изображения `model.png` и `slice.png` получены через
нативный MCP в тестовом проекте OrcaSlicer. Разговор и карточки на странице —
поясняющая демонстрация, не запись реального отправленного задания.

## Проверки

```sh
node --check website/dist/app.js
python3 website/check_site.py
```

Для прежней версии были визуально проверены ширины 390, 620 и 1440 px,
выбор клиента, копирование промпта, ручная инструкция, FAQ и переключение модели/нарезки.
Это исторические результаты для прежнего интерфейса; они не подтверждают проверку
текущих языковых страниц и не являются тестом физического мобильного устройства.
При изменении страниц заново проверяйте оба языка, переключение языка, копирование
универсального промпта, ручную инструкцию, FAQ и переключение модели/нарезки.

## Метаданные поиска и превью ссылок

Основной публичный адрес — `https://orca-agent.ru`. Обе языковые страницы
содержат собственный canonical, взаимные абсолютные hreflang и английский
x-default. robots.txt разрешает обход и указывает sitemap.xml с двумя
каноническими страницами и их языковыми вариантами. Хостинг, DNS и TLS также
должны разрешать анонимный доступ: метаданные не включают ожидающий домен.

Open Graph и Twitter используют локализованные PNG-карточки 1200x630. JSON-LD
SoftwareApplication описывает открытый проект для macOS без выдуманных оценок,
отзывов, цен и версий. Эти теги не гарантируют индексацию или расширенный результат.

При смене основного домена обновите оба HTML head, JSON-LD, robots.txt, sitemap.xml
и ORIGIN в check_site.py. Пути ресурсов остаются относительными, SEO-адреса
намеренно указывают основной домен. Карточки можно пересоздать из корня форка:
`python3 website/generate_social_images.py`. Pillow нужен только для этой
необязательной операции; размещение сайта по-прежнему не требует сборки или
Python-зависимостей. Лицензии шрифтов лежат рядом с ресурсами.
